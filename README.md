# 🎵 Sistema Musical (Front-end)

Interface web responsiva para gerenciamento de biblioteca musical, artistas e autenticação de usuários.

## 📁 Estrutura do Projeto

* `login.html`: Tela de autenticação de usuários com indicação de credenciais de teste.


* `index.html`: Menu principal e painel de navegação rápida entre os módulos do sistema.


* `cadastro_artista.html`: Formulário para cadastro de artistas (com suporte a upload de imagem) e tabela de artistas já cadastrados.


* `cadastro_musica.html`: Formulário para cadastro de músicas vinculadas a artistas, incluindo letra e links de vídeo.


* `listagem_musicas.html`: Biblioteca de músicas com filtros de busca rápida (por artista, gênero e palavra-chave) e visualização em tabela.


* `styles.css`: Folha de estilos global contendo variáveis CSS (`:root`), layouts com Flexbox/Grid e regras de responsividade.



## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica, formulários com validações nativas e tags acessíveis.


* **CSS3**: Estilização única e padronizada utilizando Variáveis CSS, Flexbox e CSS Grid.


* **Design Responsivo**: Suporte para telas móbiles e tablets por meio de `@media (max-width: 768px)`.
